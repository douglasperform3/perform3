# Perform3

Página de links responsiva, com tema claro/escuro e sem dependências externas.

## Personalizar os contatos

Edite o arquivo `index.html` antes de divulgar o site:

- **Instagram:** substitua `https://www.instagram.com/` pelo endereço do seu perfil.
- **WhatsApp:** substitua `55DDDNUMERO` pelo telefone completo, com código do país e DDD, somente números.
- **E-mail:** substitua `SEU-EMAIL@EXEMPLO.COM` pelo seu endereço.

O botão do GitHub já aponta para `douglasesquadriasperes-sketch`.

## Ativar o GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`.
4. Clique em **Save** e aguarde a publicação.

O endereço esperado é `https://douglasesquadriasperes-sketch.github.io/perform3/`.
